Install

Requires Python 3.10+ and a working Grok Build login (grok on PATH, or ~/.grok/auth.json).

git clone https://github.com/Eris-Margeta/claude-masked.git
cd claude-masked
./install.sh
export PATH="$HOME/.local/bin:$PATH"
claude --version

The installer places claude on ~/.local/bin and, when present, over Homebrew’s /opt/homebrew/bin/claude. Previous binaries are saved as claude-anthropic / claude-anthropic-homebrew.

After a brew upgrade of Claude Code, run ./install.sh again. Uninstall with ./uninstall.sh.
