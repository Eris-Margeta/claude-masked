Install

Requires a working grok on PATH (Grok Build). Python 3.10+.

git clone https://github.com/Eris-Margeta/claude-masked.git
cd claude-masked
./install.sh
# keep ~/.local/bin first on PATH
export PATH="$HOME/.local/bin:$PATH"
claude --version
# 2.1.266 (Claude Code)
# via claude-masked → grok

Existing Claude Code binaries are renamed to claude-anthropic (and Homebrew to claude-anthropic-homebrew). brew upgrade of Claude Code will restore the real binary; re-run ./install.sh.
