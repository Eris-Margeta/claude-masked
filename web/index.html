Intercept · rewrite · exec

They still type claude.
The process is Grok 4.7.

claude-masked is a drop-in CLI. Anything that shells out to the Claude Code harness — IDEs, agent UIs, scripts, CI — hits this binary instead. Flags, models, stream-json, auth status: translated. grok is what actually runs.

# grok-4.7-build · your xAI session

How this happened

A lot of software still hard-wires the Claude Code CLI. Frontends spawn claude. Scripts probe claude --version. Login panels open Anthropic OAuth because that is the binary they found on disk.

We were already on Grok Build and Codex. The missing piece was compatibility: keep the claude surface so existing tooling does not notice, send the work to Grok. Flagship aliases (Fable and friends) map to grok-4.7. Everything smaller maps to grok-4.6.

The Anthropic login page is a compatibility bug, not a requirement. If a GUI still opens claude.com/cai/oauth, it found a leftover Homebrew binary. The mask takes that path too.
