The Claude Code interface. Grok 4.7 on the wire.

claude-masked is a drop-in claude binary. Existing tools keep their CLI contract. Flagship aliases resolve to Grok 4.7; everything else to Grok 4.6. Desktop frontends that speak Claude stream-json keep native sessions via a local Anthropic-compatible proxy to api.x.ai.

Install GitHub Share on X

Why it exists

A large amount of local tooling still shells out to the Claude Code CLI: version probes, stream-json GUIs, --resume, MCP configs. Switching the model should not require rewriting those clients. This project keeps the surface and changes the inference destination to Grok Build / xAI, using the session already stored in ~/.grok/auth.json.

Two operating modes

API mask

Used for --output-format stream-json --print (and MCP-config launches). The real Claude Code binary runs. A localhost proxy on port 8317 rewrites Claude model ids and forwards Anthropic /v1/messages to https://api.x.ai. Session files, resume, and tools stay Claude’s.

Harness mask

Used for ordinary claude -p and interactive PATH calls. Arguments are translated and exec’d as grok. Auth commands (claude auth login) open Grok login.
